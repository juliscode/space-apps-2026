# Revisión con ojos de jurado

Los jueces de Space Apps evalúan 5 criterios: Impact, Creativity, Validity, Relevance y Presentation. Revisá el proyecto real (abrí la URL publicada, leé `FUENTES.md`, `demo/` y el enunciado) y puntuá cada uno de 1 a 5 con una frase de evidencia concreta.

| Criterio | Qué preguntarse |
|---|---|
| Impact | ¿Quién concreto lo usaría y qué le cambia? ¿Se entiende en la demo? |
| Creativity | ¿Qué tiene que no haría cualquier otro equipo con este desafío? |
| Validity | ¿Funciona en la URL pública? ¿Cada cifra tiene fuente? ¿Hay algo inventado o sin verificar? |
| Relevance | Marcá cada punto que pide el enunciado: ¿está cubierto? ¿Usa los datos que sugiere? |
| Presentation | ¿La demo cumple los límites (30 s o 7 slides, inglés)? ¿Se entiende sin nosotros al lado? |

## Salida
1. Tabla con puntaje y evidencia.
2. Las **3 mejoras** que más suben el puntaje con el tiempo que queda, de más barata a más cara.
3. Bloqueantes para entregar (link roto, demo pasada de tiempo, falta de fuentes), si hay.

No inflar puntajes. Si algo no se pudo verificar, decirlo.

## Checklist final de entrega
- [ ] App abre en la URL pública, en compu y celular.
- [ ] Sección de fuentes visible en la app.
- [ ] Demo dentro del límite y con link público probado en una ventana de incógnito.
- [ ] Formulario completo: equipo, desafío, links, uso de IA.
- [ ] Entregado antes de las 20:00 del domingo (cierra 23:59).
